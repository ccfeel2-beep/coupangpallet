# 쿠팡 파렛트 적재리스트 생성기 (Streamlit)

발주 엑셀을 업로드하면 기존 PPT 양식을 사용해 파렛트별 적재리스트를 생성합니다.

## 포함 파일
- `app.py`: Streamlit 웹앱 및 PPT 생성 코드
- `requirements.txt`: 자동 설치할 파이썬 라이브러리
- `쿠팡 파렛트 양식.pptx`: 기존 PPT 디자인 양식
- `README.md`: 사용 안내

## GitHub 및 Streamlit 배포
1. 압축을 풉니다.
2. GitHub에서 새 저장소를 만들거나 기존 저장소를 엽니다.
3. 이 폴더 안의 파일 4개를 저장소 최상위(root)에 업로드합니다. 폴더 자체를 한 겹 더 올리지 않도록 주의하세요.
4. Streamlit Community Cloud에서 저장소를 연결하고 Main file path에 `app.py`를 지정해 배포합니다.
5. 이미 앱을 배포했다면 GitHub에 파일을 커밋한 뒤 Streamlit 관리 화면에서 재시작하거나 새 커밋 반영을 기다립니다.

## 기능
- `.xlsx` / `.xlsm` 엑셀 업로드
- 상단의 입고예정일자, 납품센터명, 발주센터명, 발주번호 읽기
- 업체명 `주식회사 봉우리` 자동 입력
- 파렛트 번호별 슬라이드 생성
- 슬라이드 표의 NO 자동 번호 매기기
- 파렛트별 `box수량` 합계 표시
- 전체 파렛트 수-순번 형식으로 슬라이드 번호 표시 (예: 30-1부터 30-30)

## 엑셀 형식
기본 정보는 시트 상단에 `입고예정일자`, `납품센터명`, `발주센터명`, `발주번호` 이름으로 있어야 합니다.
상품 표에는 `파렛트`, `SKU No`, `SKU NAME`, `box수량`, `수량`, `제조일자` 열이 있어야 합니다. 열 이름의 공백은 일부 허용합니다.

## 보안 및 검수
- 실제 발주 파일에는 거래처 및 물류 정보가 있을 수 있으므로 회사 보안 정책에 맞게 앱 접근 권한을 관리하세요.
- 생성된 PPT를 실제 납품에 쓰기 전에 슬라이드 번호, 품목, 수량, 박스 합계와 표가 슬라이드 밖으로 넘치지 않는지 검수하세요.
- 이 패키지는 초안입니다. 웹 배포 환경에서의 전체 동작과 여러 종류의 실제 발주 엑셀은 별도로 검증해야 합니다.
